# Code of conduct

StreamZH adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies to everyone in the project's spaces: issues, pull requests, discussions and any
other channel run by the project.

In short: be respectful and welcoming, assume good intent, and focus on what is best for the community. Harassment and
personal attacks are not tolerated.

## Reporting

If you experience or witness unacceptable behaviour, report it privately to the maintainers through GitHub's
[private vulnerability reporting](https://github.com/cloudzh/streamzh/security/advisories/new) form (choose a short
title starting with "Conduct:"), or contact a maintainer directly. Reports are handled confidentially. The maintainers
decide on consequences as described in the Contributor Covenant's enforcement guidelines.
